# Power-BI-pizza-sales-prject

An interactive business intelligence **dashboard** built in **Microsoft Power BI** to analyze sales performance, customer ordering habits, and product profitability for a pizza business. This project demonstrates data modeling, DAX measures, custom UI theming, and multi-page operational reporting.

---

## Dashboard Structure 
Dashboard consists of two pages:

1. **`Home`**
Tracks high-level financial KPIs including Total Revenue, Average Order Value (AOV), Total Pizzas Sold, and Total Orders.
Visualizes temporal trends.
2. **`Best and worst sellers`**
Highlights the Top 5 Best Sellers and Bottom 5 Worst Sellers by revenue and quantity to guide inventory and promotional decisions.



---

## Key Techniques Demonstrated

* **Business Intelligence & Data Modeling:** Defining calculated columns and measures using DAX
* **Interactive Reporting:** Utilizing cross-filtering,dynamic page navigation to deliver deep analytical insights.
* **Design:**  Craeting understandable design for seamless user experience
